# Incident Response Plan

1. Detect and classify the event.
2. Protect patient safety and activate downtime workflows where necessary.
3. Contain affected accounts, hosts, interfaces or network segments.
4. Preserve logs, audit events, database evidence and volatile artefacts.
5. Eradicate the cause and validate clean restoration.
6. Recover using approved backups and clinical reconciliation.
7. Notify accountable authorities and affected parties according to applicable law and policy.
8. Complete a post-incident review, corrective-action plan and control update.

The production operator must define contacts, notification thresholds, legal timelines, severity criteria and exercise cadence.
