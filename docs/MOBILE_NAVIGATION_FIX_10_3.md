# Release 10.3 Mobile Navigation Correction

- Reworked the compact header so branding, status badges, language controls and the user avatar no longer occupy the same horizontal space.
- Hid lower-priority message/help controls at phone widths while retaining them in the full navigation drawer.
- Added a persistent five-item mobile workflow navigator for Today’s Patients, Patient Station, Workqueues, Notes and More.
- The More action opens the full left workflow rail as an accessible off-canvas drawer.
- Added safe-area spacing for iPhone home indicators and fixed workspace bottom padding.
- Added closed-state transform, visibility and pointer-event controls to the mobile workflow drawer.
