# Module Workflow Matrix

| Module | Closed-loop workflow | Connected services |
|---|---|---|
| Registration | Search MPI → duplicate review → register → coverage/consent → encounter | Scheduling, tracker, billing, audit |
| Scheduling | Public duty roster or private provider → confirm → arrive/cancel/reinstate/no-show | Registration, tracker, referral, audit, notification event |
| Patient flow | Arrive → triage → ready → room → treat → results → discharge | ADT, beds, clinical chart, transport, EVS |
| Clinical record | Select patient → encounter → document → sign/addendum | Orders, results, medications, flowsheets, referrals |
| Orders/results | Create → sign → collect/perform → result → acknowledge → follow-up | Laboratory, imaging, pharmacy, blood bank, clinical advisories |
| Medication | Reconcile → order → verify → dispense → administer/hold/refuse → review | Pharmacy, eMAR, inventory, charges |
| Flowsheets | Create → start → observe → pause/resume/change → stop | Nursing, ICU, maternity, oncology, device integration |
| Referral | Request → receiving review → schedule → encounter → return summary → acknowledge → close | MPI, scheduling, chart, national exchange |
| ADT/bed | Admit → assign/occupy → transfer → discharge → clean → available | Tracker, nursing, revenue, infection prevention |
| Revenue cycle | Eligibility → authorization → charge → claim → response/denial → payment/reconcile | Clinical record, NHIF/UHI, GePG |
| Supply chain | Receive → store → issue/transfer → reconcile → expiry/waste | Pharmacy, laboratory, theatre, finance |
| Telehealth | Select record → schedule → readiness → start/pause/resume → complete/cancel → document | Appointment, encounter, notes and orders |
| Public health | Diagnosis/result → rule → notifiable event → verification → national reporting | Laboratory, DHIS2, eIDSR, registries |
| User administration | Create account → select matrix → save/audit → sign in → update/disable/reset | Authentication, audit and facility registry |
