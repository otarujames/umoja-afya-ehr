# HIPAA Security Rule Alignment

This release supports implementation of administrative, physical and technical safeguard programmes; it does not make the deploying entity compliant by itself.

## Technical safeguard support

- Unique accounts and authenticated sessions.
- Granular user access matrix and default-deny production mode.
- Automatic session expiration and explicit logout revocation.
- Emergency access with reason, duration and audit.
- Patient-context access and minimum-necessary workflow design.
- Audit events for mutations, user administration, chart-linked actions and emergency access.
- TLS deployment profile and encrypted-transport requirements.
- Integrity controls through signed notes, state histories and database constraints.

## Administrative safeguards requiring the operator

- Enterprise risk analysis and risk-management plan.
- Security official and assigned control owners.
- Workforce authorization, termination and sanctions procedures.
- Periodic access review and security-awareness training.
- Incident response and breach-notification procedures.
- Business associate / processor management.
- Contingency plan, backup testing and emergency-mode operations.

## Physical safeguards requiring the operator

- Facility access controls.
- Workstation use and positioning standards.
- Device and media inventory, encryption and disposal.
- Data-centre and network equipment protections.
