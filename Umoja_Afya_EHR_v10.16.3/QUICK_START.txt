UMOJA AFYA EHR 10.16.3 — SECURE QUICK START

1. Linux/macOS: ./scripts/init-review.sh
   Windows PowerShell: ./scripts/init-review.ps1
2. Run: docker compose -f docker-compose.review.yml up --build
3. Open: http://localhost:8000
4. Use the one-time setup token printed by the initialization script.
5. Choose the first administrator username and password. No credentials are preloaded.
6. Rotate the bootstrap token after setup and keep the secret file protected.

Production: run ./scripts/init-production.sh, configure TLS/host settings, deploy, then complete the same first-run setup using secrets/bootstrap_token.

BROWSER INSTALL + OFFLINE
1. Production must use HTTPS.
2. Open the site in Chrome/Edge/Android or Safari on iPhone/iPad.
3. Choose Install App or Add to Home Screen.
4. Sign in online, open the Online/Sync control, and enable protected offline access.
5. Use a separate 6–12 digit offline PIN on an authorized, encrypted clinical device.
6. Reopen required patient records while online so approved responses enter the encrypted cache.
7. Reconnection sync runs when the app is open, unlocked, and authenticated online.

See docs/RELEASE_10_15_OFFLINE_PWA.md for supported offline workflows and safeguards.
