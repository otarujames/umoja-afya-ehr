UMOJA AFYA EHR 10.12.0 — SECURE QUICK START

1. Linux/macOS: ./scripts/init-review.sh
   Windows PowerShell: ./scripts/init-review.ps1
2. Run: docker compose -f docker-compose.review.yml up --build
3. Open: http://localhost:8000
4. Use the one-time setup token printed by the initialization script.
5. Choose the first administrator username and password. No credentials are preloaded.
6. Rotate the bootstrap token after setup and keep the secret file protected.

Production: run ./scripts/init-production.sh, configure TLS/host settings, deploy, then complete the same first-run setup using secrets/bootstrap_token.
